# Security & Child Safety Policy

NextNTech.org is used by children, so we treat security and child-safety problems as our
highest priority.

## Reporting a problem

**Please do not open a public issue** for security vulnerabilities or child-safety
concerns.

Instead, report it privately through GitHub:
**Security tab → "Report a vulnerability"** on this repository
(https://github.com/PDostiyar/NextNtech/security/advisories/new).

Please include:

- What you found and where (page, URL or file).
- Steps to reproduce it.
- What could happen if someone abused it.

We'll acknowledge your report as soon as we can, keep you updated, and credit you when
it's fixed (unless you'd rather stay anonymous).

## What counts

- Anything that exposes learners' personal data (names, emails, birth years, progress).
- Ways around parental consent for under-13 accounts.
- Account takeover, login or session bugs.
- Code playgrounds escaping their sandbox.
- Quiz answers leaking to the browser before a learner answers.
- Inappropriate content reachable by learners.
- Anything that lets someone contact or identify a child.

## Supported versions

Only the latest version on the `main` branch (the live site) is supported. Fixes are made
on `staging` first and released to `main`.
