# NextNTech.org — Curriculum Outline

**Prepared for:** Pervaiz Dostiyar | NextNTech — July 2026
Every module ends with **3–5 quiz questions** saved to the learner's profile. Every course ends with a **named certificate**.

---

## Course 1 · Front-End Development

**Module 1 — HTML Foundations**
1. What is the web? Browsers, servers, and pages
2. The history of HTML — Tim Berners-Lee, 1991, and how the web grew
3. Your first page: tags, elements, and structure
4. Old tags vs. new tags (goodbye `<font>` and `<center>`, hello HTML5)
5. Text, headings, lists, and links
6. Images, audio, and video
7. Tables and forms
8. Semantic HTML: `<header>`, `<section>`, `<article>`, `<footer>`
9. Project: build your "About Me" page

**Module 2 — CSS & Layout**
1. What CSS does — the clothes of the web
2. Selectors, colors, and fonts
3. The box model (margin, border, padding)
4. Flexbox — arranging things in rows and columns
5. CSS Grid — full page layouts
6. Responsive design: making pages work on phones
7. Transitions and simple animations
8. Project: style your "About Me" page for phone and desktop

**Module 3 — JavaScript Basics**
1. What JavaScript does — the muscles of the web
2. Variables, numbers, and strings
3. If/else — teaching the page to decide
4. Loops — doing things many times
5. Functions — reusable magic spells
6. The DOM: changing the page with code
7. Events: clicks, typing, and scrolling
8. Project: an interactive quiz game

**Module 4 — React**
1. Why React exists — components as LEGO bricks
2. JSX and your first component
3. Props and state
4. Handling events and forms in React
5. Lists, keys, and rendering data
6. Project: rebuild your quiz game in React

*Note: PHP lives in the Back-End course — it runs on servers, not in the browser.*

---

## Course 2 · Back-End Development

**Module 1 — Node.js & Express**
1. What is a server? Front end vs. back end
2. Node.js: JavaScript outside the browser
3. Your first Express server and routes
4. APIs and JSON — how apps talk to each other
5. Middleware and handling requests
6. Project: build a jokes API

**Module 2 — Databases & SQL**
1. What is a database and why apps need one
2. Tables, rows, and columns
3. SELECT, INSERT, UPDATE, DELETE
4. Relationships: connecting tables together
5. Connecting your Express app to a database
6. Project: a guestbook that remembers visitors

**Module 3 — PHP & Its Frameworks**
1. PHP: the language that powers most of the web
2. PHP basics: variables, forms, and includes
3. Laravel: the modern PHP framework
4. CodeIgniter: the lightweight alternative
5. When to choose PHP vs. Node.js
6. Project: a contact form with Laravel

**Module 4 — CMS: WordPress, Joomla & Drupal**
1. What a CMS is and why 40% of the web runs on one
2. WordPress: themes, plugins, and pages
3. Joomla and Drupal: how they compare
4. Customizing a WordPress theme with your HTML/CSS skills
5. Project: build a small site with WordPress

## Course 3 · Full-Stack Development

**Module 1 — Connecting Front & Back**
1. How React talks to Express (fetch and APIs)
2. Sending and receiving data
3. Handling errors kindly
4. Project: a to-do app with a real database

**Module 2 — Auth & Accounts**
1. How login works: sessions, tokens, passwords
2. Never store plain passwords — hashing explained
3. Social login (Google & friends) in simple terms
4. Project: add accounts to your to-do app

**Module 3 — Deploying Your App**
1. What "deploying" means — putting your app on the internet
2. Domains, hosting, and environment variables
3. Free hosting: Vercel, Railway, Render
4. Project: put your app live and share the link

**Module 4 — Capstone Project**
1. Plan it: pick an idea and sketch the pages
2. Build it: front end + back end + database
3. Test it and fix bugs
4. Present it — your first portfolio piece 🎓

## Course 4 · Python: Basic to Advanced

**Module 1 — Python Basics**
1. Why Python is the friendliest first language
2. print(), input(), and variables
3. Numbers, strings, and f-strings
4. If/else decisions
5. Loops
6. Project: a number-guessing game

**Module 2 — Data & Logic**
1. Lists and dictionaries
2. Functions
3. Reading and writing files
4. Handling errors with try/except
5. Project: a personal expense tracker

**Module 3 — Advanced Python**
1. Classes and objects (OOP, gently)
2. Modules and pip — using other people's code
3. Working with APIs and JSON
4. Virtual environments
5. Project: a weather app using a real API

**Module 4 — Build with Python**
1. Flask: Python for the web
2. Automating boring tasks (files, emails, reports)
3. A taste of data: pandas and charts
4. Where Python leads: AI, data science, DevOps
5. Project: your own Flask mini-site

## Course 5 · Mobile Apps (Android & iOS)

**Module 1 — Mobile Basics:** how phone apps differ from websites; native vs. cross-platform; app stores explained.
**Module 2 — React Native:** reuse your React skills; components, navigation, styling; project: a flashcard study app.
**Module 3 — Swift & iOS:** Swift basics; SwiftUI views; project: a simple iPhone counter app. (Plus a look at Kotlin for Android.)
**Module 4 — Publish Your App:** icons and screenshots; Google Play and App Store submission; updates and reviews.

---

## Course 6 · Careers & Side Hustles

**Module 1 — Your Portfolio:** GitHub, a portfolio site (you can build one now!), and telling your story.
**Module 2 — Freelance Platforms:** Fiverr, Upwork, and Freelancer — profiles, gigs, first proposals, fair pricing, avoiding scams.
**Module 3 — Remote Jobs:** where to find them (LinkedIn, remote job boards), junior-friendly roles, resumes and interviews for young developers.
**Module 4 — Working with Clients:** communication, deadlines, revisions, getting paid safely, and growing from side hustle to career.

## Learner journey summary

Sign up (social or email) → pick a path → read short visual lessons → practice in the playground → answer 3–5 questions per module (saved to profile) → keep the daily streak → finish the course → receive a named certificate → share the invite link and bring a friend.
